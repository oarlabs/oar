# Reports directory

Subagent reports land here, one directory per stage, saved verbatim and
never committed by the subagent itself. See `CLAUDE.md`, "Subagents never
commit."

This file exists so a fresh clone carries this directory: git does not
track an empty one, and the rules file names this path before any report
does. Delete it once a real report lands here, or leave it; it costs
nothing either way.
